## 어제 구름 얘기, 기억나시나요?

어제는 [구름으로 배우는 뉴럴 셰이더]({{< relref "2026-11-13-neural-shader-volumetric-clouds.md" >}}) 글을 소개했습니다.
공식 대신 작은 신경망을 셰이더 안에 넣었더니, 구름 밝기가 정답에 확 가까워졌다는 이야기였지요.

그런데 글을 올리고 나서 곰곰이 생각해 보니...
"셰이더 안에서는 그냥 곱셈-덧셈 반복문이에요, 별거 없어요" 해 놓고, 정작 **그 숫자들이 어디서 어떻게 나오는지**는 제대로 안 보여 드렸더라고요 (...)

그래서 오늘은 직접 만들어 봅니다.
구름은 너무 어려우니까, 훨씬 쉬운 걸로요. **화면에 하트 하나 그리기**입니다.

약속 하나 드리고 시작하겠습니다. 오늘 필요한 수학은 딱 세 가지예요.

- 곱하기
- 더하기
- 0보다 작으면 0으로 자르기

네, 중학교 1학년이면 충분합니다. 진짜로요.

## 오늘 만들 것

보통 셰이더로 하트를 그리려면 하트 공식을 셰이더에 적어 넣습니다.
오늘은 반대로 해 봅니다. 셰이더에는 하트 공식을 **한 줄도 안 넣습니다.**

대신 이렇게 합니다.

1. 파이썬으로 "여기는 하트 안, 여기는 하트 밖"이라는 **정답 그림**을 한 장 만든다.
2. 아주 작은 신경망한테 그 그림을 보여 주면서 **따라 그리는 연습**을 시킨다.
3. 연습이 끝나면 신경망 속 숫자 337개를 뽑아서 **셰이더에 그대로 붙여 넣는다.**

그러면 셰이더는 하트가 뭔지 하나도 모르는데도 하트를 그립니다. 어제 구름 글이랑 완전히 같은 흐름이지요. 크기만 아주 작을 뿐입니다.

신경망한테 주는 입력은 화면 위의 위치, 그러니까 셰이더 하시는 분들한테 익숙한 **UV 좌표**입니다.
처음 보시는 분을 위해 설명하면, 네모 판의 왼쪽 아래를 (0, 0), 오른쪽 위를 (1, 1)로 정한 주소예요. 가로 위치가 u, 세로 위치가 v.
신경망은 이 두 숫자를 받아서 "여기는 하트 안쪽이 얼마나 되나"를 0~1 사이 숫자 하나로 내놓습니다. 1이면 하트, 0이면 배경.

## 뉴런 하나가 하는 일

'신경망'이라고 하면 뭔가 뇌처럼 복잡한 걸 상상하시는데, 그 안에 든 '뉴런' 하나가 하는 일은 정말 별거 없습니다.

![뉴런 하나의 계산 과정. u와 v에 각각 가중치를 곱해 더하고, 0보다 작으면 0으로 자른다](/images/tech-art/neural-shader-heart-tutorial/neuron.png)
*뉴런 하나가 하는 일 전부. 오른쪽은 '자르기'를 그래프로 그린 것. (직접 만든 그림)*

- 들어온 숫자마다 **정해진 수를 곱합니다.** 이 곱하는 수를 **가중치**(weight)라고 부릅니다.
- 곱한 것들을 다 **더하고**, 거기에 정해진 수를 하나 더 더합니다. 이건 **편향**(bias)이라고 하는데, 그냥 "덤으로 더하는 수"라고 생각하시면 됩니다.
- 마지막으로 결과가 **0보다 작으면 0으로 자릅니다.** 0보다 크면 그대로 둡니다. 이 자르기를 어려운 말로 **ReLU**(렐루)라고 부릅니다.

끝입니다. 생각보다 별거 없지요?

그런데 이 뉴런 하나를 화면 전체에 대고 계산해 보면 재밌는 일이 생깁니다.
u, v에 곱하고 더한 값이 딱 0이 되는 곳은 화면 위에 **직선 하나**로 나타납니다. 중학교 때 배운 일차함수 그래프 그거요.
그 직선 한쪽은 전부 0으로 잘려서 깜깜하고, 반대쪽은 직선에서 멀어질수록 점점 밝아집니다. 화면을 직선으로 반 가르고 한쪽에만 **비탈길**을 깐 모양이지요.

![학습이 끝난 신경망의 1층 뉴런 16개가 각자 그리는 그림. 전부 직선 하나로 나뉜 비탈길 모양이다](/images/tech-art/neural-shader-heart-tutorial/layer1.png)
*오늘 학습시킨 신경망의 1층 뉴런 16개를 하나씩 따로 그려 본 것. 전부 '직선 하나 + 비탈길'입니다. (직접 만든 그림)*

뉴런 하나로는 직선 하나밖에 못 긋습니다. 하트는 꿈도 못 꾸지요.

## 뉴런을 모으고, 층을 쌓으면

그럼 어떻게 하냐고요? **여러 개를 모으면 됩니다.**

오늘 쓸 신경망은 이렇게 생겼습니다.

![입력 2개, 1층 뉴런 16개, 2층 뉴런 16개, 출력 1개로 된 신경망 도식](/images/tech-art/neural-shader-heart-tutorial/network.png)
*오늘 만들 신경망. 회색 선 하나하나가 곱하기 하나입니다. (직접 만든 그림)*

- **1층**: 뉴런 16개가 각자 u, v를 받아서 계산합니다. 직선 16개가 생기는 셈이지요.
- **2층**: 뉴런 16개가 이번에는 u, v 대신 **1층의 결과 16개**를 받아서, 똑같이 곱하고 더하고 자릅니다.
- **출력**: 2층 결과 16개에 곱하고 더해서 숫자 하나를 냅니다. 이게 하트 안쪽인 정도예요. (여기서는 자르기를 안 합니다.)

곱하는 수와 더하는 수를 다 세어 보면 1층 48개, 2층 272개, 출력 17개. 합쳐서 **337개**입니다.
신경망을 '학습시킨다'는 건 결국 이 337개 숫자를 잘 맞추는 일이에요.

2층이 왜 중요하냐면, 비탈길 여러 개를 섞으면 꺾인 모양을 만들 수 있거든요.

![2층 뉴런 16개가 각자 그리는 그림. 1층보다 훨씬 복잡한 꺾인 모양들이 보인다](/images/tech-art/neural-shader-heart-tutorial/layer2.png)
*2층 뉴런들은 1층의 직선 비탈길을 섞어서 꺾인 모양을 만듭니다. 오른쪽 아래 뉴런은 벌써 하트 아랫부분을 닮았지요. 아예 깜깜한 뉴런은 학습 중에 일을 안 하게 된 '노는' 뉴런입니다. (직접 만든 그림)*

비유하자면 **색종이를 가위로 반듯하게 몇 번 잘라서 하트를 오려 내는 것**과 비슷합니다. 한 번 자를 때는 직선이지만, 여러 번 자르면 둥근 모양도 비슷하게 나오잖아요.
다만 이 비유가 안 맞는 부분도 있습니다. 색종이는 자르면 딱 떨어지는데, 신경망의 자른 자리는 비탈길이라 가장자리가 부드럽게 번집니다. 이건 결과 그림에서 다시 보실 거예요.

## 학습: 틀린 만큼 조금씩 고치기

처음엔 337개 숫자를 그냥 **아무렇게나**(랜덤으로) 정합니다. 당연히 엉뚱한 그림이 나오지요.
그다음엔 이걸 수천 번 반복합니다.

1. 지금 숫자들로 그림을 그려 본다.
2. 정답 그림과 칸마다 비교해서 **얼마나 틀렸는지** 점수를 매긴다.
3. 337개 숫자 각각에 대해 "이걸 살짝 올리면 틀림이 줄어드나, 늘어나나"를 계산해서, **줄어드는 쪽으로 아주 조금씩** 고친다.

3번의 계산을 **역전파**(backpropagation)라고 부르는데, 출력에서부터 거꾸로 거슬러 올라가며 "누구 탓이 얼마나 큰지" 따지는 계산이라 그런 이름이 붙었습니다.
저도 처음엔 이 부분이 제일 무서웠는데, 오늘은 몰라도 괜찮습니다. 코드에 세 줄로 들어 있고, "틀림이 줄어드는 방향을 알려 주는 계산"이라는 것만 아시면 돼요.

흔히 쓰는 비유는 **눈 가리고 산 내려가기**입니다. 앞이 안 보여도 발밑이 어느 쪽으로 기울었는지는 알 수 있으니까, 내리막 쪽으로 한 발짝씩 가다 보면 골짜기에 닿는다는 거지요.
이 비유도 안 맞는 데가 있습니다. 진짜 산은 방향이 동서남북뿐인데, 이 산은 숫자가 337개라 방향이 337개예요. 그리고 꼭 **제일 낮은 골짜기**에 도착한다는 보장도 없습니다. 실제로 처음 숫자를 다르게 뽑으면 하트 모양이 조금씩 다르게 나옵니다.

학습이 진행되는 모습을 찍어 보면 이렇습니다.

## 따라 하기 1: 파이썬으로 학습시키기

자, 이제 직접 해 봅시다.

준비물은 파이썬과 numpy 하나뿐입니다. 파이썬을 설치하셨다면 명령 창에서 이렇게 numpy 를 설치해 주세요.

```bash
pip install numpy
```

그다음 아래 코드를 `heart_nn.py` 라는 이름으로 저장하고 `python heart_nn.py` 로 실행합니다. ([파일로 받기](/images/tech-art/neural-shader-heart-tutorial/heart_nn.py))

```python
# heart_nn.py : 하트를 그리는 아주 작은 신경망 (numpy 만 씁니다)
import numpy as np

# 1) 정답 그림 만들기: 64x64 칸마다 "하트 안이면 1, 밖이면 0"
N = 64
g = (np.arange(N) + 0.5) / N                 # 0~1 사이 좌표
U, V = np.meshgrid(g, g)
x, y = (U - 0.5) * 3.0, (V - 0.45) * 3.0     # 하트 공식에 맞게 좌표를 옮기고 키움
answer = (((x*x + y*y - 1)**3 - x*x * y**3) <= 0).astype(float).reshape(-1, 1)
inputs = np.stack([U.ravel(), V.ravel()], 1) * 2 - 1   # (u, v)를 -1~1 로

# 2) 신경망 준비: 입력 2개 → 뉴런 16개 → 뉴런 16개 → 출력 1개
rng = np.random.default_rng(11)
W1 = rng.normal(0, 3.0, (2, 16));  b1 = rng.uniform(-2, 2, 16)
W2 = rng.normal(0, 0.35, (16, 16)); b2 = np.zeros(16)
W3 = rng.normal(0, 0.35, (16, 1));  b3 = np.zeros(1)
params = [W1, b1, W2, b2, W3, b3]

def relu(z):                     # 0보다 작으면 0으로 자르기
    return np.maximum(z, 0)

def forward(p):                  # 곱하고, 더하고, 자르기를 층마다 반복
    z1 = p @ W1 + b1; h1 = relu(z1)
    z2 = h1 @ W2 + b2; h2 = relu(z2)
    out = h2 @ W3 + b3
    return z1, h1, z2, h2, out

def picture():                   # 지금 신경망이 그리는 그림 (0~1로 자름)
    return np.clip(forward(inputs)[-1], 0, 1).reshape(N, N)

# 3) 학습: 틀린 만큼 가중치를 조금씩 고치기를 수천 번
m = [np.zeros_like(q) for q in params]; s = [np.zeros_like(q) for q in params]
for step in range(1, 8001):
    z1, h1, z2, h2, out = forward(inputs)
    err = out - answer                       # 얼마나 틀렸나
    d3 = 2 * err / len(inputs)               # 여기서부터는 "어느 가중치를 얼마나
    d2 = (d3 @ W3.T) * (z2 > 0)              #  고치면 틀림이 줄어드나"를 거꾸로
    d1 = (d2 @ W2.T) * (z1 > 0)              #  거슬러 올라가며 계산 (역전파)
    grads = [inputs.T @ d1, d1.sum(0), h1.T @ d2, d2.sum(0), h2.T @ d3, d3.sum(0)]
    lr = 0.01 * (1 - step / 8001) + 0.0005   # 고치는 폭: 처음엔 크게, 갈수록 작게
    for i, (q, gq) in enumerate(zip(params, grads)):   # Adam 이라는 고치는 요령
        m[i] = 0.9 * m[i] + 0.1 * gq
        s[i] = 0.999 * s[i] + 0.001 * gq * gq
        q -= lr * (m[i] / (1 - 0.9**step)) / (np.sqrt(s[i] / (1 - 0.999**step)) + 1e-8)
    if step % 1000 == 0:
        print(f"step {step:5d}  틀린 정도 {np.mean(err**2):.4f}")

# 다 배운 그림을 글자로 찍어 보기 (두 칸에 한 번씩)
for row in picture()[::-2, ::2]:
    print("".join("#" if v > 0.5 else "." for v in row))

# 4) 셰이더에 붙여 넣을 숫자 출력
def arr(a):
    return ", ".join(f"{v:.4f}" for v in np.ravel(a))
with open("weights.hlsl", "w") as f:
    f.write(f"static const float2 W1[16] = {{ {', '.join(f'float2({a:.4f}, {b:.4f})' for a, b in W1.T)} }};\n")
    f.write(f"static const float  B1[16] = {{ {arr(b1)} }};\n")
    f.write("static const float  W2[16][16] = {\n" + ",\n".join("    { " + arr(W2[:, j]) + " }" for j in range(16)) + "\n};\n")
    f.write(f"static const float  B2[16] = {{ {arr(b2)} }};\n")
    f.write(f"static const float  W3[16] = {{ {arr(W3)} }};\n")
    f.write(f"static const float  B3 = {b3[0]:.4f};\n")
print("weights.hlsl 저장 완료")
```

코드가 길어 보이지만 하는 일은 위에서 설명한 그대로예요.

- **1번**은 정답 그림 만들기. 하트 공식은 여기에만, 파이썬 쪽에만 들어갑니다.
- **2번**은 337개 숫자를 아무렇게나 정하기. `rng = np.random.default_rng(11)` 의 11을 바꾸면 처음 숫자가 바뀌어서 결과도 조금 달라집니다.
- **3번**이 학습. 8000번 고치는 데 제 컴퓨터로 10초 남짓 걸렸습니다.
- **4번**은 다 배운 숫자를 셰이더에 붙여 넣기 좋은 모양으로 `weights.hlsl` 파일에 써 주는 부분.

## 따라 하기 2: 유니티 셰이더에 붙여 넣기

이제 `weights.hlsl` 파일을 열어 보면 숫자가 잔뜩 들어 있을 겁니다. 이게 신경망의 전부예요.

유니티에서는 이렇게 합니다.

1. Project 창에서 마우스 오른쪽 → Create → Shader → Unlit Shader 를 만들고, 이름을 `NeuralHeart` 로 바꿉니다.
2. 파일을 열어 안에 있는 내용을 **전부 지우고** 아래 코드를 통째로 붙여 넣습니다.
3. 머티리얼을 하나 만들고, 셰이더를 `JP/NeuralHeart` 로 고릅니다.
4. Hierarchy 창에서 3D Object → Quad 를 만들고 그 머티리얼을 끌어다 놓으면 끝.

아래 코드에 들어 있는 숫자는 위 파이썬 코드를 그대로 돌렸을 때 나오는 숫자라서, 파이썬을 안 돌려 보셔도 바로 하트가 나옵니다. 직접 학습시킨 숫자로 바꾸고 싶으면 `=====` 줄 사이를 `weights.hlsl` 내용으로 갈아 끼우시면 돼요. ([파일로 받기](/images/tech-art/neural-shader-heart-tutorial/NeuralHeart.shader))

```hlsl
Shader "JP/NeuralHeart"
{
    Properties
    {
        _Color   ("Heart Color", Color) = (1, 0.25, 0.45, 1)
        _BgColor ("Background",  Color) = (0.05, 0.05, 0.08, 1)
    }
    SubShader
    {
        Tags { "RenderType" = "Opaque" }
        Pass
        {
            CGPROGRAM
            #pragma vertex vert
            #pragma fragment frag
            #include "UnityCG.cginc"

            float4 _Color;
            float4 _BgColor;

            // ===== 파이썬이 만들어 준 숫자 (weights.hlsl 내용을 통째로 붙여 넣는 곳) =====
            static const float2 W1[16] = { float2(0.3898, 3.0054), float2(4.0667, -0.7728), float2(3.7889, -0.0888), float2(-2.2581, 1.6197), float2(-0.9200, -2.6495), float2(-1.8161, -5.0265), float2(2.0580, 1.0981), float2(-1.9595, -2.2533), float2(2.8580, -6.3455), float2(-6.1301, -3.4829), float2(5.1234, -1.6234), float2(-0.2195, -3.2234), float2(1.5147, -4.7966), float2(-0.6339, -0.0305), float2(-1.1930, 2.9474), float2(1.8119, -2.0790) };
            static const float  B1[16] = { -1.8631, 2.0276, -0.0294, -2.3483, 0.5998, -1.3544, 1.5247, -1.7019, -1.6031, -2.5660, -1.2087, -0.3879, 1.7553, 0.8569, -1.1985, -1.5397 };
            static const float  W2[16][16] = {
                { -0.4844, 0.2324, 0.1659, -0.4520, 0.2548, -0.1855, -0.2984, -0.0631, -0.2740, 0.3954, -0.1214, -0.0788, 0.2570, -0.2610, 0.8109, -0.2376 },
                { -0.2586, -0.3067, 0.4400, 0.1040, 0.0219, 0.1147, -0.0324, 0.1604, -0.0576, 0.0155, -0.0443, -0.3604, -0.3022, -0.2170, -0.2411, 0.1195 },

            static const float  W3[16] = { -0.2278, 0.1182, -0.9999, -0.0809, -0.9351, -0.7948, 0.5065, -0.7550, 0.6366, -0.4667, -0.6364, 1.0435, -0.0794, -0.8195, -0.0753, 1.3493 };

            // 신경망: (u, v) 두 숫자를 넣으면 '하트 안쪽인 정도'(0~1)가 나온다
            float NeuralHeart(float2 uv)
            {
                float2 p = uv * 2 - 1;            // 0~1 을 -1~1 로 (학습 때와 똑같이)

                // 1층: 뉴런 16개. 곱하고, 더하고, 0보다 작으면 0으로 자르기
                float h1[16];
                [unroll] for (int j = 0; j < 16; j++)
                    h1[j] = max(0, dot(W1[j], p) + B1[j]);

                // 2층: 뉴런 16개. 1층 결과 16개를 받아서 똑같이
                float result = B3;
                [unroll] for (int k = 0; k < 16; k++)
                {
                    float s = B2[k];
                    [unroll] for (int i = 0; i < 16; i++)
                        s += W2[k][i] * h1[i];
                    result += W3[k] * max(0, s);  // 출력: 곱해서 더하기만
                }
                return saturate(result);          // 0~1 밖으로 나간 건 잘라 내기
            }

            struct v2f
            {
                float4 pos : SV_POSITION;
                float2 uv  : TEXCOORD0;
            };

            v2f vert(appdata_base v)
            {
                v2f o;
                o.pos = UnityObjectToClipPos(v.vertex);
                o.uv  = v.texcoord.xy;
                return o;
            }

            fixed4 frag(v2f i) : SV_Target
            {
                float a = NeuralHeart(i.uv);
                a = smoothstep(0.3, 0.7, a);      // 가장자리를 조금 또렷하게 (지워도 됨)
                return lerp(_BgColor, _Color, a);
            }
            ENDCG
        }
    }
}
```

셰이더에서 진짜 신경망 부분은 `NeuralHeart` 함수 하나뿐입니다.
반복문 두 개로 "곱하고, 더하고, 0보다 작으면 0으로 자르기"(`max(0, ...)`)를 층마다 하는 게 다예요. 파이썬 쪽 `forward` 함수랑 한 줄 한 줄 똑같지요.

그리고 중요한 거 하나. 학습 때 u, v를 -1~1로 바꿔서 가르쳤으니까, 셰이더에서도 **똑같이** `uv * 2 - 1` 로 바꿔 줘야 합니다.
이거 빼먹으면 신경망이 처음 보는 동네에 떨어진 셈이 돼서 엉뚱한 그림이 나옵니다. 어제 구름 글에서 "연습 때 못 본 상황을 만나면 엉뚱한 답을 낸다"고 했던 게 바로 이런 거예요.

제가 확인한 방법도 솔직히 적어 두겠습니다. 이 셰이더는 유니티 에디터에서 찍은 게 아니라, 셰이더 컴파일러로 문법 검사를 하고 소프트웨어 GPU로 실제로 그려서 파이썬 결과와 같은지 비교했습니다. 칸마다 차이가 0.006 이하로 같게 나왔고요.
기본(Built-in) 렌더 파이프라인용으로 쓴 코드입니다. 혹시 여러분 유니티에서 다르게 나오면 댓글로 알려 주세요.

## 결과

![왼쪽은 64×64칸 정답 그림, 오른쪽은 셰이더가 512×512로 그린 하트](/images/tech-art/neural-shader-heart-tutorial/result.png)
*왼쪽은 학습에 쓴 정답 그림, 오른쪽은 셰이더 계산 그대로 512×512로 그린 결과. (직접 만든 그림)*

몇 가지 재밌는 점이 보입니다.

**계단이 없습니다.** 정답 그림은 64×64칸짜리라 가장자리가 계단처럼 깨져 있지요. 그런데 신경망은 '칸'을 외운 게 아니라 '좌표를 넣으면 밝기가 나오는 계산'을 배운 거라서, 512로 그리든 4K로 그리든 계단 없이 매끈하게 나옵니다. 텍스처와 제일 다른 점이에요.

**어깨가 좀 각졌습니다.** 하트의 둥근 어깨가 다각형처럼 보이지요? 아까 봤듯이 뉴런 하나하나가 직선이라서, 결국 직선 조각을 이어 붙인 모양이 나오는 겁니다. 색종이를 몇 번 안 자른 셈이지요. 뉴런을 늘리면 더 둥글어지는 대신 숫자도 늘어납니다.

**가장자리가 살짝 번집니다.** 비탈길 때문이에요. 그래서 셰이더 `frag` 함수에 `smoothstep` 한 줄을 넣어 가장자리를 조금 또렷하게 했습니다. 이 줄을 지우면 신경망이 내놓은 그대로를 보실 수 있어요.

## 생각해 볼 만한 것

- **사실 하트는 공식으로 그리는 게 훨씬 쌉니다.** 하트 공식은 몇 줄이면 되는데, 오늘 신경망은 픽셀마다 곱하기를 300번 넘게 합니다. 오늘 예제는 "이렇게 하면 이득이다"가 아니라 "신경망 셰이더가 이렇게 생겼다"를 보여 드리려는 거예요. 신경망이 제값을 하는 건 어제 구름처럼 **깔끔한 공식이 아예 없거나, 공식이 너무 무거운 경우**입니다.
- **셰이더 입장에서 신경망은 그냥 '숫자 덩어리'입니다.** 337개 숫자를 텍스처에 넣든 배열에 넣든, 결국 곱하고 더하는 데이터예요. 그래서 학습은 셰이더 밖(파이썬)에서 하고, 셰이더는 계산만 하는 이 역할 분담이 어제 구름 글에서도, 엔비디아의 큰 발표에서도 똑같습니다. 크기만 다를 뿐이지요.
- **같은 코드로 모양만 바꿔 볼 수 있습니다.** 파이썬 1번의 하트 공식을 원(`x*x + y*y <= 1`)이나 별 모양으로 바꾸면, 셰이더는 한 글자도 안 고치고 숫자만 갈아 끼워서 다른 모양을 그립니다. 반대로 별처럼 뾰족한 모양일수록 뉴런 16개로는 모자랄 거예요. 직접 해 보시면 "신경망 크기가 얼마나 필요한가"를 몸으로 느끼실 수 있습니다.
- **"재 보는 습관"은 여기서도 통합니다.** 이 글의 숫자(틀린 정도, 0.006 차이)는 전부 직접 돌려서 잰 것입니다. 눈으로 "하트 같네" 하고 넘어가지 않고 숫자로 확인하는 것, 어제 구름 글에서 제일 값지다고 했던 그 습관을 이렇게 작은 예제에서부터 들여 두면 좋겠다는 생각이 듭니다.
